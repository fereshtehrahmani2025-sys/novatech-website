# Novatech | Persian Corporate Website

A modern, responsive, right-to-left (RTL) corporate website designed and developed as an independent portfolio project.

## 🌐 Live Demo

**[View Live Website](https://fereshtehrahmani2025-sys.github.io/novatech-website/)**

## ✨ Features

- Modern and clean corporate design
- Fully responsive layout for desktop and mobile
- Persian language and RTL support
- Mobile-friendly navigation
- Five website pages: Home, Services, About, Portfolio, and Contact
- Contact form integrated with FormSubmit
- Interactive elements using JavaScript

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages
- FormSubmit

## 📱 Responsive Design

The website automatically adapts its layout to different screen sizes, providing a user-friendly experience on desktop and mobile devices.

## 📄 Pages

- `index.html` — Home
- `services.html` — Services
- `about.html` — About
- `portfolio.html` — Portfolio
- `contact.html` — Contact

## 🎯 Project Purpose

This project was independently developed to demonstrate front-end web development skills, responsive design, Persian RTL interfaces, and integration with an external form submission service.

**Project Type:** Personal Portfolio / Demonstration Project
